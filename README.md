# Sesion07
🌍 Explorador Global - Rest Countries API
Una aplicación web interactiva y responsiva diseñada para explorar datos detallados de países de todo el mundo. Este proyecto se enfoca en una experiencia de usuario (UX) fluida y un diseño limpio/minimalista.

🚀 Características
Búsqueda en Tiempo Real: Filtra países por nombre mientras escribes.

Filtros Avanzados: Clasifica la información por continentes e idiomas principales.

Diseño Responsivo: Interfaz adaptativa construida con Bootstrap 5, optimizada para móviles y escritorio.

Consumo de API: Integración directa con la API pública de Rest Countries.

Feedback Visual: Indicador de carga (spinner) y estados de "no resultados".

🛠️ Tecnologías Utilizadas
HTML5 / CSS3: Estructura y estilos personalizados.

Bootstrap 5: Sistema de rejilla (Grid) y componentes de interfaz.

JavaScript (Vanilla): Lógica de filtrado, manejo del DOM y peticiones fetch.

📦 Instalación y Uso
No requiere ninguna configuración compleja o dependencias de Node.js.

Clona este repositorio o descarga los archivos.

Abre el archivo index.html en tu navegador preferido.

Bash
# Ejemplo para abrir desde la terminal si tienes VS Code
code index.html
📋 Detalles Técnicos
La aplicación extrae y procesa los siguientes campos de la API:

name.common: Nombre común del país.

flags.svg: Bandera en formato vectorial.

capital: Capital administrativa.

population: Población total (formateada con separadores locales).

languages: Idiomas oficiales.

currencies: Moneda local.
